# Week 7

At first, I planned to project on two walls and the floor, but later I found a corner where two walls and the ceiling meet. I think this space is more interesting because all three surfaces connect at one point.

I thought it could be like a black hole, where everything is being pulled into the corner. But I didn't want to just show the same animation on all three surfaces. I wanted them to look different but still connected.

I first tried some basic shapes like circles, lines, and squares, but the result was a little boring. So I decided to try something more like Generative Art. I started with the left wall, making ribbons with different colors, widths, and curves moving toward the corner. I also tried using a class for the ribbons, so each one has its own properties, and used update() and display() to control them.

After finishing the left wall, I wasn't really sure what to do with the other two surfaces, so I searched for some Generative Art online for inspiration. I ended up using a distorted grid for the right wall, and repeated geometric lines for the ceiling. I also changed the visuals a few times, like making the ribbons wider because the thin lines didn't look good enough, and adjusting the grid because the bottom part was too empty.\

The hardest part for me was the math, especially how to make the curves and distorted patterns. I used an LLM to help with the coding and math calculations. Some earlier versions were too complicated for me, so I tried to simplify the code while keeping the similar visual effect. I think this also helped me understand more about how changing different values can affect the final result.
