# Week 4 Reflection

After looking at some pen plotter art online, I found that I really liked the feeling of many lines and geometric shapes overlapping with each other. For this project, I did not want to use too many different shapes. Instead, I wanted to see what could happen if I repeated one simple shape many times. I ended up using a rectangle, an ellipse, and a diagonal line as the basic unit, then changed the size, angle, and position of each layer so they gradually overlapped with each other.

At first, I set the value in the for loop too high, which made the whole drawing extremely dense. It looked interesting on the screen, but I started worrying about how it would actually look when drawn with the pen plotter. Since I was using relatively thick colored pens, I thought too many overlapping lines might become messy and hard to read. Because of that, I reduced the number of layers and made a simpler version with more space between the lines.

When I actually used the pen plotter, I was surprised that the result looked better than I expected. On the second and third prints, I added a small amount of offset so that the drawings were not perfectly aligned with each other. These small misalignments created some unexpected overlaps, and I really liked the final effect. It made the pattern feel less rigid and gave the drawing a little more character.

Later, after I got home, I noticed that the assignment seemed to ask for two versions, Week 4.1 and Week 4.2. For the second version, I did not redesign the whole system. Instead, I changed a few parameters. The main change was increasing the number of layers from around 10 to 20, which made the whole pattern much denser again. I also saw students from another section using ballpoint pens, so I started thinking that this denser version might actually work really well with a thinner pen. More of the overlapping lines and details could remain visible without becoming as messy as they might with a thicker pen.

I thought this assignment was really fun, especially because turning something from the screen into a physical drawing felt very different from only looking at it on the computer. I think one of the most interesting things about the pen plotter is that sometimes adding a small offset, or keeping things slightly imperfect, can actually make the work more interesting and even become my favorite part of the result.
